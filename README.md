# Norden Global Handelhus (NGHS) & Salsabil International

High-end, tactical web presentation and logistics portal inspired by Arkham Intelligence aesthetics for cross-border procurement and supply chain governance.

## Key Features
- **Tactical Dark Luxury Aesthetic**: Pure black backdrop (`#000000`), crisp white typography, and high-impact red CTAs.
- **Fullscreen Slide Deck Controller**: Smooth sequential opacity transitions (`100% -> 0%` fade-out, `0% -> 100%` fade-in) with HUD indicators and tactile navigation.
- **Arkham-Style Text Decryption**: Real-time cipher scrambling and decrypt animation on headlines, links, and action buttons.
- **Dedicated Subpages**:
  - `on-field.html` — Operational intel & deployment reports carousel
  - `product.html` — Global performance & execution capabilities grid
  - `contact.html` — Cross-border logistics operations inquiry desk
  - `legals.html` — Terms of service, privacy policy & compliance documentation
- **Interactive Modals & Transmitters**: Freight quote dispatcher and article briefing overlays.

## Structure
- `index.html` — Main slide presentation deck
- `on-field.html` — On-Field reports view
- `product.html` — Product execution matrix
- `contact.html` — Contact desk
- `legals.html` — Legal governance & terms
- `css/main.css` — Core design system and styles
- `js/slides.js` — Presentation slide deck engine
- `js/cipher.js` — Text scramble / cipher engine
- `js/app.js` — Modal, form, and interface interactions
- `assets/` — Clean imagery, transparent emblems, and vectors
